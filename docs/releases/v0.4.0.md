# Stealth Prompt 0.4.0

Version 0.4.0 adds automatic objective selection and makes Local Core setup easier to
discover from the extension.

## Highlights

- **Auto — let AI choose** maps the target's visible capabilities, chooses one concrete
  security objective supported by evidence, and keeps that focus until a pivot is
  justified.
- The Auto objective works through both Local Core and Direct API. It is independent
  from Auto behavior and never grants send authorization by itself.
- Local Core setup documentation is linked directly beside the connection controls,
  whether Core is connected or not.
- Custom Objective has clearer visual separation from its selector.

## Upgrade notes

There are no stored-state, scenario, report, protocol, or Chrome-permission migrations.
Update the extension and Local Core together so the Core catalogue and the panel expose
the same objective list. The packaged extension version is 0.4.0 for Chrome Web Store
submission.
