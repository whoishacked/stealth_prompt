# Chrome Web Store notes — 0.4.0

This update adds **Auto — let AI choose** for assessments where the most relevant
security category is not known in advance. The planner maps visible capabilities,
selects one evidence-backed objective, and keeps that focus until a pivot is justified.

Local Core setup help is now linked directly from the connection step, and the Custom
Objective field has clearer spacing.

Auto objective selection is independent from Auto sending. It does not change send
authorization, saved-data behavior, network access, or Chrome permissions. No new
permissions or remote executable code are included.
