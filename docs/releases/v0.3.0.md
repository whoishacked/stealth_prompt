# Stealth Prompt 0.3.0

Version 0.3.0 adds FrameFuzz matched framing experiments to the browser extension and
Local Core while preserving ordinary assessment and report formats.

## Highlights

- deterministic `framefuzz-core` v1 templates for clean control, explicit injection,
  integrity signature, required configuration, and trusted destination cases;
- one normalized semantic seed and reproducible fixed or randomized case order;
- a mandatory fresh-conversation gate and read-only binding validation before every
  case, with send authorization scoped to that case only;
- Core conclusions backed by deterministic scorer provenance and Direct API conclusions
  capped at potential;
- in-product campaign progress and report comparison, plus JSON and self-contained HTML
  evidence;
- scenario schema v3 with safe FrameFuzz configuration and backward-compatible v1/v2
  import with the feature disabled;
- a local framing-sensitive demo and a safe negative control exercised end to end in
  real Chromium.

FrameFuzz is intentionally limited to compatible indirect-injection and disclosure
objectives. It does not add navigation, arbitrary clicks, target resets, new Chrome
permissions, remote code, or a model-driven prompt mutation surface.

## Upgrade notes

Update the extension and Local Core together. A new extension connected to an older
Core keeps FrameFuzz disabled until the Core advertises the capability. Existing
scenarios and ordinary reports remain readable. Reloading the Side Panel never restores
automatic-send authorization.

The Chrome Web Store version preceding this release is 0.2.0. Submit the generated
0.3.0 extension ZIP through the existing store account after the GitHub release checks
are green.
