# Stealth Prompt 0.4.1

Version 0.4.1 makes response capture faster to diagnose and recover when a chat
interface does not expose a stable assistant-message element.

## Highlights

- Page capture now shows a 15-second countdown instead of waiting silently.
- A timed-out turn can check the same post-send snapshot again, re-detect the
  response element, or continue with one operator-provided response. Retrying never
  resends the payload.
- Assist and Guided runs can replace a missing or incorrect capture without starting
  a new assessment.
- Response capture follows sibling message envelopes used by component-based chat
  widgets and rejects page-level containers that also contain the chat controls.
- FrameFuzz turns off automatically when the selected objective is incompatible, and
  its toggle retains the intended compact layout.

## Upgrade notes

Update the extension and Local Core together. The manual recovery path during Auto
uses the 0.4.1 Core contract, while Direct API recovery is contained in the extension.
There are no new Chrome permissions or stored-state migrations.
