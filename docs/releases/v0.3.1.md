# Stealth Prompt 0.3.1

Version 0.3.1 is a maintenance release. It updates the extension, documentation,
CI, and release toolchains without changing assessment behavior or Chrome
permissions.

## Highlights

- TypeScript 7.0.2, esbuild 0.28.2, and Chrome types 0.2.7;
- Node types remain on version 22 to match the supported build runtime;
- Zensical 0.0.57 for documentation builds;
- maintained Node 24-based GitHub Actions for checkout, Node/Python setup,
  artifact upload, and GitHub Releases;
- an exact esbuild postinstall allowlist matching the installed version.

## Upgrade notes

There are no configuration, protocol, scenario, report, or stored-state
migrations in this release. Local Core and extension behavior are unchanged.
The packaged extension version is 0.3.1 so the same verified artifact can be
submitted to the Chrome Web Store.
